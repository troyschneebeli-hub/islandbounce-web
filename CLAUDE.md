# Island Bounce Travel (islandbouncetravel.com): project notes

Next.js 14 (app router) ferry-comparison affiliate site on Vercel. Owner: Troy (ClankINC partner). Earns via 12Go affiliate.

## Money and links
- 12Go affiliate ID `17069158` (param `z`), `sub_id=islandbounce-web`. White label: `https://booking.islandbouncetravel.com`.
- Links are built in `lib/affiliateLinks.js` / `lib/bookingLink.js`: `/en/travel/<from>/<to>?date=&date2=&people=&adults=`. Slug quirk: our `benoa-nusa-dua` redirects to 12Go's `tanjung-benoa-nusa-dua`; confirm `z` survives the redirect.
- 12Go has no open API. Never call 12Go's internal endpoints (e.g. `/api/nuxt/.../tripsV2/search`). Official option (12Go support, 19 Oct 2026): the partner **Timetable Service**, a PHP library `timetable.php` (dashboard > Timetable > Integration, downloadable only when logged in), `get12GoTimetable(country, from, dest, class, noreturn, lesslinks, lang, curr)` returning HTML. We run Next.js on Vercel (no PHP); Troy is asking 12Go for the endpoint/parameters or the file. Route/operator URL parameters are NOT supported; dashboard > Links makes verified route deep links.
- Per-sailing deep links are NOT possible: "Book now" is an add-to-cart button, checkout URLs are cart IDs. Time chips link to the route page with date/travellers prefilled. Ask 12Go about trip-level links.
- Never click Book now / add to cart on the live booking site to test.

## Timetable data
- `data/timetables.js`: AUTO-GENERATED from the operator research sheet by `scripts/build_timetables.py`. Operator-verified ("confirmed") plus some "unconfirmed" rows.
- `data/twelvego.js`: AUTO-GENERATED by `scripts/build_twelvego.py` from `scripts/12go-master-routes.xlsx` (sheet "Master Routes"). Listings read from the 12Go booking page for Tue 20 Oct 2026 (A$, per adult), ASSUMED IDENTICAL EVERY DAY, check-in = 1h before departure. Published as "unconfirmed". Only "Scheduled boat" rows with times; transfer packages, flights, private charters and hotel/port pickup packages stay in the spreadsheet only. Rows are skipped where an operator we have confirmed already covers the same port pair.
- `data/sailings.js` merges both. Import SAILINGS from there, not from timetables.js.
- Re-capture roughly monthly (route pages may have changed), rebuild the xlsx, then run `python3 scripts/build_twelvego.py`. Known thin capture: Padang Bai -> Nusa Penida; captured 962 of ~1,760 header trips overall (see "Route Summary" sheet).
- `data/planner.js` BOAT_ROUTES decides which port/destination pairs the Trip Planner offers; extend it when new pairs get data.

## Planner UI
- `components/FindPortMap.js`: port cards with `DepartureList` (operators, times, fares; chips link to booking page). `lib/portDepartures.js` groups sailings per operator.
- `components/RouteTimetable.js`: route page tables (has a From (adult) price column).
